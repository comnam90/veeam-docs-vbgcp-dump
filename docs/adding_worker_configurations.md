# Adding Worker Configurations


To add a new worker configuration, do the following:

1. [Launch the Add Worker Configuration wizard](worker_wizard.md).
2. [Specify general settings for the worker configuration](worker_general_settings.md).
3. [Specify network settings for the worker configuration](worker_network_settings.md).
4. [Check the required prerequisites](worker_prerequisites.md).
5. [Finish working with the wizard](worker_finish.md).
