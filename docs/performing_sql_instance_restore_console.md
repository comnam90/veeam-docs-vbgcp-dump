# Performing SQL Instance Restore


In case a disaster strikes, you can restore an entire Cloud SQL instance from a cloud-native snapshot or an image-level backup. Veeam Backup & Replication allows you to restore one or more Cloud SQL instances at a time, to the original location or to a new location. To learn how Cloud SQL restore works, see [Performing Instance Restore](performing_sql_instance_restore_ui.md).

To restore a Cloud SQL instance, do the following:

1. [Launch the Restore to Google Cloud SQL wizard](restore_sql_instance_launch.md).
2. [Select a restore point](restore_sql_instance_restore_point.md).
3. [Choose a restore mode](restore_sql_instance_mode.md).
4. [Select a project, region and an availability zone](restore_sql_instance_region.md).
5. [Specify instance type and name](restore_sql_instance_type.md).
6. [Configure network settings](restore_sql_instance_network.md).
7. [Configure security settings](restore_sql_instance_security.md).
8. [Enable flag assignment](restore_sql_instance_flags.md).
9. [Specify a restore reason](restore_sql_instance_reason.md).
10. [Finish working with the wizard](restore_sql_instance_finish.md).
