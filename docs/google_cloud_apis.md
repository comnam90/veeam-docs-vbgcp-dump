In this article

Veeam Plug-in for Google Cloud, backup appliance and worker instances must have outbound internet access to the following Google Cloud APIs:

* [Compute Engine API](https://cloud.google.com/compute/docs/api/libraries)
* [Service Usage API](https://cloud.google.com/service-usage/docs/reference/rest)
* [IAM Service Account Credentials API](https://cloud.google.com/iam/docs/reference/credentials/rest)
* [Identity and Access Management (IAM) API](https://cloud.google.com/iam/docs/reference/rest)
* [Cloud Resource Manager API](https://docs.cloud.google.com/resource-manager/docs/apis)
* [Cloud Billing API](https://cloud.google.com/billing/docs/apis)
* [Pub/Sub API](https://cloud.google.com/pubsub/docs/apis)
* [Cloud Key Management Service API](https://cloud.google.com/kms/docs/apis)
* [Cloud SQL Admin API](https://cloud.google.com/sql/docs/mysql/admin-api/rest)
* [Cloud Logging API](https://cloud.google.com/logging/docs/apis)
* [Cloud Spanner API](https://cloud.google.com/spanner/docs/apis)

* [Cloud Infrastructure Manager API](https://docs.cloud.google.com/infrastructure-manager/docs/reference/rest)
* [Cloud Identity-Aware Proxy API](https://cloud.google.com/iap/docs/reference/rest)
