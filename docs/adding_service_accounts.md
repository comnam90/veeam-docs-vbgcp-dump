# Adding Service Accounts


To add a new service account, do the following:

1. [Launch the Add Service Account wizard](service_account_wizard.md).
2. [Choose a service account type](service_account_type.md).
3. [Specify a project for the service account](service_account_project.md).
4. [Specify service account details](service_account_id.md).
5. [Track the account creation progress](service_account_progress.md).
6. [Finish working with the wizard](service_account_finish.md).
