In this article

To add a new backup repository, do the following:

1. [Launch the Add Repository wizard](repository_wizard.md).
2. [Specify a repository name and description](repository_name.md).
3. [Specify a project for the repository](repository_project.md).
4. [Specify a HMAC key for the repository](repository_account.md).
5. [Configure repository settings](repository_settings.md).
6. [Enable encryption for the repository](repository_encryption.md).
7. [Finish working with the wizard](repository_finish.md).
