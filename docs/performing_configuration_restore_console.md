In this article

To restore the configuration database of a backup appliance using the Veeam Backup & Replication console, do the following:

1. [Check prerequisites and limitations](config_restore_launch.md).
2. [Launch the Configuration Restore wizard](config_restore_launch.md).
3. [Choose a backup file](config_restore_file.md).
4. [Review the backup file info](config_restore_file_info.md).
5. [Specify a decryption password](restore_config_password.md).
6. [Choose restore options](config_restore_options.md).
7. [Specify a user whose credentials will be used to connect to the appliance](restore_config_account.md).
8. [Wait for the restore process to complete](restore_config_review.md).
9. [Finish working with the wizard](config_restore_finish.md).
