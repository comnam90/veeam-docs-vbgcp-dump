In this article

Veeam Backup for Google Cloud offers the following restore operations:

* [Instance restore](spanner_restore_instance.md) — start an entire Cloud Spanner instance from a restore point.
* [Database restore](performing_spanner_database_restore_ui.md) — restore specific databases of a Cloud Spanner instance.

You can restore Cloud Spanner instance data to the most recent state or to any available restore point.
