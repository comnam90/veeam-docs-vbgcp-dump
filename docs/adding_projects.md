In this article

To add a new project or folder, do the following:

1. [Launch the Add Projects and Folders wizard](project_wizard.md).
2. [Specify a service account to access the project or folder](project_service_account.md).
3. [Define operations to perform in the project or folder](project_tasks.md).
4. [Select the project or folder](project_id.md).
5. [Check the required permissions](project_permissions.md).
6. [Finish working with the wizard](project_finish.md).
