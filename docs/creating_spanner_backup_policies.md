In this article

To create a backup policy, do the following:

1. [Launch the Add Cloud Spanner Policy wizard](spanner_policy_wizard.md).
2. [Specify a backup policy name and description](spanner_policy_name.md).
3. [Choose a project in which Cloud Spanner instances that you plan to back up reside](spanner_policy_project.md).
4. [Configure backup source settings](spanner_policy_source.md).
5. [Configure backup target settings](spanner_policy_target.md).
6. [Create a schedule for the backup policy](spanner_policy_schedule.md).
7. [Specify automatic retry, health check and notification settings for the backup policy](spanner_policy_notifications.md).
8. [Review the estimated cost of protecting the selected Cloud Spanner instances](spanner_policy_cost.md).
9. [Check the required permissions](spanner_policy_permissions.md).
10. [Finish working with the wizard](spanner_policy_finish.md).
