# Creating Backup Policies


To create a backup policy, do the following:

1. [Launch the Add VM Policy wizard](backup_policy_wizard.md).
2. [Specify a backup policy name and description](backup_policy_name.md).
3. [Choose a project in which VM instances that you plan to back up reside](backup_policy_project.md).
4. [Configure backup source settings](backup_policy_source.md).
5. [Configure backup target settings](backup_policy_target.md).
6. [Create a schedule for the backup policy](backup_policy_schedule.md).
7. [Enable label assignment](backup_policy_labels.md).
8. [Specify automatic retry, health check and notification settings for the backup policy](backup_policy_notifications.md).
9. [Review the estimated cost of protecting the selected VM instances](backup_policy_cost.md).
10. [Check the required permissions](backup_policy_permissions.md).
11. [Finish working with the wizard](backup_policy_finish.md).
