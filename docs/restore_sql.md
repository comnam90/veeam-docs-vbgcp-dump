In this article

Veeam Backup for Google Cloud offers the following restore operations:

* [Instance restore](restore_entire_instance_sql.md) — start an entire Cloud SQL instance from a restore point.
* [Database restore](restore_database.md) — restore specific databases of a Cloud SQL instance.

You can restore Cloud SQL instance data to the most recent state or to any available restore point.
