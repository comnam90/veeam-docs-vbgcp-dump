In this article

Veeam Backup for Google Cloud offers the following restore operations:

* [Instance restore](performing_instance_restore_ui.md) — start an entire VM instance from a restore point.
* [Disk restore](performing_disk_restore.md) — restore persistent disks attached to a VM instance.
* [File-level recovery](performing_flr.md) — recover individual files and folders of a VM instance.

You can restore VM instance data to the most recent state or to any available restore point.
