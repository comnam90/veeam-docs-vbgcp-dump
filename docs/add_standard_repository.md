# Creating New Repositories


To add a new repository, do the following:

1. [Launch the Add External Repository wizard](add_repo_launch.md).
2. [Specify an appliance, and provide a repository name and description](add_repo_appliance.md).
3. [Specify a project for the repository](add_repo_project.md).
4. [Specify a service account that will be used to access the project](add_repo_service_account.md).
5. [Configure repository settings](add_repo_bucket.md).
6. [Wait for the repository to be added to the backup infrastructure](add_repo_apply.md).
7. [Finish working with the wizard](add_repo_finish.md).
