# Updating Appliances Using Web UI


Veeam Backup for Google Cloud automatically notifies you about newly released package updates available for the operating system running on the backup appliance. However, starting from Veeam Backup for Google Cloud version 5.0, you can use the Veeam Backup for Google Cloud Web UI to install package updates only. To upgrade Veeam Backup for Google Cloud to new versions, follow the instructions provided in section [Upgrading Appliances](upgrade_vb_console.md).
