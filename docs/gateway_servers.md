In this article

A gateway server is an auxiliary backup infrastructure components that provide access from the backup server to repositories. By default, the role of a gateway server is assigned to the backup server.

Gateway servers cache data when you copy backups and restore application items, which helps you decrease the amount of traffic being sent over the network and reduce data transfer costs. For more information on caching data, see the Veeam Backup & Replication User Guide, section [Cache](https://helpcenter.veeam.com/docs/vbr/userguide/external_repository_cache.html?ver=13).
