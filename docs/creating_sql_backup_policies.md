# Creating Backup Policies


To create a backup policy, do the following:

1. [Launch the Add Cloud SQL Policy wizard](sql_policy_wizard.md).
2. [Specify a backup policy name and description](sql_policy_name.md).
3. [Choose a project in which Cloud SQL instances that you plan to back up reside](sql_policy_project.md).
4. [Configure backup source settings](sql_policy_source.md).
5. [Configure backup target settings](sql_policy_target.md).
6. [Create a schedule for the backup policy](sql_policy_schedule.md).
7. [Choose whether you want to use a staging server to perform backup](sql_policy_processing.md).
8. [Specify automatic retry, health check and notification settings for the backup policy](sql_policy_notifications.md).
9. [Review the estimated cost of protecting the selected Cloud SQL instances](sql_policy_cost.md).
10. [Check the required permissions](sql_policy_permissions.md).
11. [Finish working with the wizard](sql_policy_finish.md).
